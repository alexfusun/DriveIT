# 🚗 DriveIT

> A modern car discovery and review platform for Spanish users — find, compare, and explore vehicles through trusted publisher reviews.

---

## About

DriveIT is a full-stack web application where users can browse detailed car specifications, compare vehicles side by side, and read in-depth reviews written by verified publishers. A like-based reputation system rewards the best contributors, and admins manage the publisher ecosystem through a dedicated panel.

The project was built as a hands-on practice exercise for **Spring Boot** backend development, with the frontend generated by **Claude (Anthropic)** as a reference implementation.

---

## Features

- 🔍 **Car catalog** — browse and filter by brand, model, year, fuel type, and price range
- ⚖️ **Side-by-side comparator** — compare up to 4 cars across 50+ technical data points
- 📝 **Publisher reviews** — verified publishers write structured reviews with pros, cons, and ratings
- ❤️ **Like system** — users can like reviews; likes build a publisher's reputation score
- 🏅 **Publisher ranks** — Bronze → Silver → Gold → Platinum, assigned by admins
- 👤 **Three-tier roles** — USER, PUBLISHER, and ADMIN with distinct permissions
- 🔐 **JWT authentication** — secure, stateless auth across all protected endpoints

## API Overview

Base URL: `http://localhost:8080/api/v1`

| Resource | Endpoint | Auth |
|---|---|---|
| Auth | `POST /auth/register`, `POST /auth/login` | Public |
| Brands | `GET /brands`, `GET /brands/{id}/models` | Public |
| Cars | `GET /cars`, `GET /cars/{id}` | Public |
| Cars (admin) | `POST /cars`, `PUT /cars/{id}`, `DELETE /cars/{id}` | `ADMIN` |
| Comparator | `GET /cars/compare?ids=1,2,3` | Public |
| Reviews | `GET /cars/{id}/reviews` | Public |
| Reviews (write) | `POST /cars/{id}/reviews`, `PUT /reviews/{id}` | `PUBLISHER` |
| Likes | `POST /reviews/{id}/like`, `DELETE /reviews/{id}/like` | `USER` |
| Publishers | `GET /publishers`, `GET /publishers/{id}` | Public |
| Users | `GET /users/me`, `PUT /users/me` | `USER / PUBLISHER` |
| Admin | `PATCH /admin/users/{id}/role`, `PATCH /admin/publishers/{id}/rank` | `ADMIN` |

Full contract with request/response schemas: [`docs/api-contract.md`](docs/api-contract.md)

## Roles

| Role | Description |
|---|---|
| `USER` | Registered user. Can browse content and like publisher reviews. |
| `PUBLISHER` | Trusted contributor. Can write and manage car reviews. Earns reputation via likes. |
| `ADMIN` | Platform manager. Manages the car catalog, promotes users to publishers, and assigns ranks. |

### Publisher Ranks
Ranks are assigned manually by admins (automatic milestones planned for a future version):

`BRONZE` → `SILVER` → `GOLD` → `PLATINUM`

## Getting Started

### Prerequisites
- Java 21+
- Node.js 20+
- PostgreSQL 15+ (or Docker)
- Maven 3.9+

### 1. Clone the repo

```bash
git clone https://github.com/your-username/driveIT.git
cd driveIT
```

### 2. Start the database

```bash
docker run --name driveit-db \
  -e POSTGRES_DB=driveit \
  -e POSTGRES_USER=driveit \
  -e POSTGRES_PASSWORD=driveit \
  -p 5432:5432 -d postgres:15
```

### 3. Configure the backend

```bash
cd backend
cp src/main/resources/application.example.yml src/main/resources/application.yml
# Edit application.yml with your DB credentials and JWT secret
```

### 4. Run the backend

```bash
./mvnw spring-boot:run
# API available at http://localhost:8080
```

### 5. Run the frontend

```bash
cd ../frontend
npm install
npm run dev
# App available at http://localhost:5173
```
